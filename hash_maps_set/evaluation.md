
# Character Frequency Counter

## Problem
Count how many times each character appears
in a given string.

## Data Structure
Python Dictionary (Hash Map).

## Implementation
Iterate through the string and update the
frequency of each character.

## Complexity Analysis
- Time Complexity: O(n) average
- Space Complexity: O(k)

Where:
- n = total number of characters
- k = number of distinct characters

## Testing
- Total tests: 6
- Passed: 6
- Failed: 0

## Conclusion
A dictionary provides an efficient way to
count character frequencies using average
constant-time lookups and updates.
