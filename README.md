
# Python Algorithms & Data Structures

A practical Python project demonstrating fundamental
programming concepts, data structures, and algorithms.

## Projects

### 1. Find First Duplicate
- Implemented using nested loops and Python Sets.
- Compared two approaches.
- Analyzed time and space complexity.
- Added automated tests using Pytest.

### 2. Character Frequency Counter
- Used Python Dictionaries (Hash Maps).
- Counted character occurrences in strings.
- Tested different inputs and edge cases.
- Analyzed time and space complexity.

### 3. Binary Search
- Implemented iterative Binary Search.
- Searched for elements in sorted lists.
- Tested successful and unsuccessful searches.
- Analyzed algorithm complexity.
